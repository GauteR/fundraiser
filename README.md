# Fundraiser

Guild donation reminders for **World of Warcraft: Forever**.

Officers set a shared fundraising goal; members get bag reminders until they mail the designated recipient. Ledger and install presence sync over a thin guild addon channel.

| --- | --- |
| Interface | `16001` (Forever) |
| Slash command | `/fundraiser` |
| Language | English (UI and docs) |
